# 项目简介
本项目是制作一个两轮差速后驱导航小车，主控采用ESP32S3开发板和ESP32-s3-cam视觉模块，上位机基于ros2+qt进行开发，下位机基于Arduino框架进行开发，使用ros2中的slam_toolbox进行建图和nav2进行导航。

# 开发环境
- 系统：ubuntu22.04
- ros2：humble
- qt：5.X
- 插件：vscode中的platformio插件
